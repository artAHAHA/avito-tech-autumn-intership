1. [ADS] Сбрасывается сортировка после перехода в карточку объявления и возврата к списку

Приоритет: Medium

Серьёзность: Major

Окружение:

Страница: /ads

Браузер: Chrome

Устройство: Desktop

Предусловия:

Открыта страница «Мои объявления».
В списке доступно несколько объявлений.

Шаги воспроизведения:

1. Открыть страницу /ads.
2. В поле сортировки выбрать «По новизне (сначала старые)».
3. Убедиться, что сортировка применилась.
4. Открыть любую карточку объявления.
5. Вернуться обратно к списку объявлений.

Ожидаемый результат:
После возврата из карточки объявления выбранная ранее сортировка «По новизне (сначала старые)» должна сохраняться, а список объявлений должен отображаться с применённой сортировкой.

Фактический результат:
После возврата на страницу списка выбранная сортировка сбрасывается на значение по умолчанию «По новизне (сначала новые)». Пользовательская сортировка «сначала старые» не сохраняется.

Примечание: баг воспроизводится при выборе любой из сортировок
