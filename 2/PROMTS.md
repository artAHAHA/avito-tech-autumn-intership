Я написал тест-кейсы на пользовательские сценарии кабинета продавца для работы с объявлениями.

## Тестируемая платформа

Платформа состоит из следующих страниц:

- `/ads` — страница списка объявлений;
- `/ads/:id` — страница просмотра объявления;
- `/ads/:id/edit` — страница редактирования объявления.

## Требования к автоматизированным тестам

Автоматизированные тесты должны быть реализованы на **Python + Selenium**.

К тестам предъявляются следующие требования:

- Обязательна проверка результатов выполнения с помощью **assertions**.
- При обнаружении бага тест должен завершаться с ошибкой, а итоговый отчёт должен **явно отражать наличие бага**.
- Отчёт о прохождении тестов должен быть **лаконичным и понятным**.
- Если ошибок и багов нет, **все тесты должны проходить успешно**.
- Не допускаются «сломанные» тесты: каждый тест должен либо:
  - успешно проходить при корректной работе приложения;
  - падать только в случае обнаружения реального бага.

## Особенности общего тестового стенда

Тестирование выполняется на общем стенде, поэтому данные могут изменяться другими пользователями во время выполнения тестов.

При разработке автотестов необходимо учитывать это:

- не опираться на фиксированное количество объявлений;
- не использовать заранее заданные ID объявлений;
- не использовать заранее заданные названия объявлений;
- не предполагать, что конкретные записи останутся неизменными;
- выбирать тестовые данные непосредственно из фактически загруженного списка объявлений;
- не проверять точный текст ответа AI;
- после изменения объявления по возможности восстанавливать исходные данные;
- избегать проверок, зависящих от конкретного состояния общего тестового стенда.
