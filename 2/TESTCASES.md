# 2. Страница редактирования объявления

**URL:** `/ads/:id/edit`

**Общие предусловия:**

* В списке существует доступное пользователю объявление.

---

### EDIT-01 — Валидация обязательных полей

**Приоритет:** High

**Предусловия:**

* Открыта страница редактирования объявления.
* Объявление содержит заполненные обязательные поля.

**Шаги:**

| № | Действие                                            | Ожидаемый результат                                                               |
|---| --------------------------------------------------- |-----------------------------------------------------------------------------------|
| 1 | Запомнить исходные значения обязательных полей      | Значения сохранены                                                                |
| 2 | Очистить первое обязательное поле                   | Поле становится пустым, появляется предупреждение, что поле должно быть заполнено |
| 3 | Нажать кнопку сохранения                            | Форма не сохраняется, повляется уведомление "Пожалуйста, проверьте правильность заполнения полей"                                      | |
| 4 | Повторить проверку для остальных обязательных полей | Для каждого обязательного поля выполняется валидация                              |

**Ожидаемый результат:** форма не позволяет сохранить объявление с незаполненными обязательными полями.

---

### EDIT-02 — Сохранение изменений объявления

**Приоритет:** Critical

**Предусловия:**

**Шаги:**

| № | Действие                                       | Ожидаемый результат                 |
| - | ---------------------------------------------- | ----------------------------------- |

| 2 | Изменить значение поля                         | Новое значение отображается в форме |
| 3 | Нажать кнопку сохранения                       | Изменения сохраняются               |
| 4 | Открыть сохранённое объявление                 | Отображается страница объявления    |
| 5 | Проверить изменённое поле                      | Отображается новое значение         |

**Ожидаемый результат:** изменения объявления успешно сохраняются и отображаются после сохранения.
